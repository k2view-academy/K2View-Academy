# Task — Execution Report Tab

The **Execution report** tab in the task's **Advanced settings** enables configuring what is included in the task's execution report.

The following options are available:

## Include Statistics Report

When enabled, the execution report lists the processed tables and their source and target record counts, per processed entity.

The **Scope** drop-down controls which tables are included in the report:

- **All** — the report includes all processed tables for each processed entity.

## Include Sequence Replacement Report

When enabled, the execution report lists the source and target ID mappings for the processed tables, per processed entity.

# Fabric 8.x with PostgreSQL Setup

**Mandatory required details:**
+ SystemDB type (POSTGRESQL)
+ Postgresql node IP
+ Postgresql user & password
+ Kafka node IPs (if kafka_ips is not provided, the [PubSub](/articles/24_non_DB_interfaces/02a_pubsub_config.md) will run 'in memory')



1. Run the following command, replacing the parameters with your own environment:
~~~bash
/opt/apps/fabric/fabric/scripts/fabric-setup.sh --systemdb POSTGRESQL --systemdb-user k2admin --systemdb-password changeit ---systemdb-host 10.0.0.1  --kafka-host 10.0.0.4,10.0.0.5,10.0.0.6 
~~~

* If the PostgreSQL & Kafka are Hardened with SSL, add the switch --ssl to import the certificate to Fabric Truststore
~~~bash
/opt/apps/fabric/fabric/scripts/fabric-setup.sh --systemdb POSTGRESQL --cassandra_user k2admin --cassandra_password changeit --cassandra_ips 10.0.0.1 --kafka_ips 10.0.0.4,10.0.0.5,10.0.0.6 --ssl
~~~

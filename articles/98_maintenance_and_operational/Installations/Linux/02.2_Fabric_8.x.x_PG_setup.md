# Fabric 8 with PostgreSQL Setup

This section describes how to configure Fabric 8.x to use PostgreSQL as its System Database.

---

## Prerequisites

The following information is required before running the setup:

- SystemDB type: `POSTGRESQL`
- PostgreSQL node IP address or cluster VIP
- PostgreSQL user and password with appropriate privileges
- Kafka node IP addresses (optional; only required for multi-node deployments)

> **Note:**  
> If Kafka nodes are not provided, Fabric's PubSub component will run in in-memory mode, which is suitable for development and single-node setups only.  
> Refer to [PubSub Configuration](/articles/24_non_DB_interfaces/02a_pubsub_config.md) for additional details.

---

## Fabric Setup Command

Run the following command on each Fabric node to configure PostgreSQL as the SystemDB, replacing the placeholders with your actual values:

~~~bash
/opt/apps/fabric/fabric/scripts/fabric-setup.sh \
  --systemdb POSTGRESQL \
  --systemdb-user k2admin \
  --systemdb-password changeit \
  --systemdb-host 10.0.0.1
~~~

> **Note:**  
> If your PostgreSQL deployment uses multiple nodes (HA, cluster VIP, or read-replicas), specify the appropriate host address or load balancer endpoint.

---

## Kafka Integration (Optional)

If your deployment includes Kafka (for multi-node Fabric clusters or durable Pub/Sub use cases), append the Kafka node IPs to the setup command:

~~~bash
--kafka-host 10.0.0.4,10.0.0.5,10.0.0.6
~~~

---

## SSL / TLS (Optional Hardening)

If your PostgreSQL and/or Kafka instances are configured to require SSL:

- Add the `--ssl` switch to the `fabric-setup.sh` command.  
- The SSL certificates will be imported into Fabric’s truststore automatically.

~~~bash
--ssl
~~~

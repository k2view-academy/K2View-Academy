 # Fabric 8.x with SQlite Setup

**Mandatory required details:**
+ SystemDB type (SQLITE)
+ Path for the SQlite file to be saved
+ Since SQLite is aimed for single node, the [PubSub](/articles/24_non_DB_interfaces/02a_pubsub_config.md) will run 'in memory'



1. Run the following command, replacing the parameters with your own environment:
~~~bash
/opt/apps/fabric/fabric/scripts/fabric-setup.sh --systemdb SQLITE  ---systemdb-host 10.0.0.1  -
~~~

# Fabric 8 with SQLite Setup

This section describes how to configure Fabric 8.x to use SQLite as its System Database.

---

## Overview

SQLite is supported for lightweight, single-node, or development environments.
It is fully embedded within Fabric and requires minimal external configuration.

> **Note:**  
> Since SQLite is a file-based database intended for single-node operation, Fabric’s PubSub component will automatically run in in-memory mode.  
> For details on PubSub behavior, refer to:  
> [PubSub Configuration](/articles/24_non_DB_interfaces/02a_pubsub_config.md)

---

## Prerequisites

The following information is required:

- SystemDB type: `SQLITE`
- Path where the SQLite database file should be created and stored

---

## Fabric Setup Command

Run the following command, replacing the parameters with your environment-specific values:

~~~bash
/opt/apps/fabric/fabric/scripts/fabric-setup.sh \
  --systemdb-type SQLITE \
  --systemdb-host /opt/apps/fabric/storage/system_db
~~~

> **Note:**  
> Replace the `--systemdb-host` value with the full path where you want the SQLite database file to reside.

---

## Additional Notes

- SQLite is not recommended for production workloads.
- No SSL configuration is required for SQLite deployments.

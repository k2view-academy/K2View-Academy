# K2cloud Space Profile Naming 

K2cloud’s **versionless** Space Profiles standardize sizing across environments and are available out-of-the-box (OOTB).

* **Existing customers:** ask us to enable these profiles on your tenant.
* **New customers:** profiles are available at provisioning.

To learn about these please see the [K2cloud Space Profile topic](/articles/98_installation_and_upgrade/Hardware_K8s/05_k2cloud_space_profiles.md)


# Digital Signature Verification for K2view Fabric & Studio Artifacts

K2view provides cryptographic signatures of Fabric and Studio container images and Fabric packages, enabling customers to independently verify their authenticity and integrity. The verification procedures are documented on the K2view Support Portal at https://support.k2view.com/signatures.

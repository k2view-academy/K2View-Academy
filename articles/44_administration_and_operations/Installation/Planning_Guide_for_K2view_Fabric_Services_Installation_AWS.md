# Installation Planning Guide for K2view Fabric Services on Amazon AWS


## Abstract

The *Installation Planning Guide for K2view Fabric Services on Amazon AWS* provides a structured roadmap for preparing, provisioning, and deploying K2view Fabric Services on AWS infrastructure. It covers phases including gathering environment details, choosing persistent storage, configuring security, managing container images, and setting correct IAM permissions. The guide includes a detailed checklist, worksheet, and template variables (via Terraform/EKS) to help administrators plan their AWS environments for reliability, scalability, and compliance. By following the prerequisites and configuration steps, customers can ensure a smooth installation and setup of Projects and Spaces under the K2view platform.

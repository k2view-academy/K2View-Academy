# Installation Planning Guide for K2view Fabric Services on Microsoft Azure 

## Abstract

The *Installation Planning Guide for K2view Fabric Services on Microsoft Azure* (v1.4) provides a detailed framework for preparing an Azure environment to deploy K2view Fabric Services securely, reliably, and at scale. It walks through obtaining required environment information, provisioning Azure resources (including AKS, storage, container registries), configuring DNS, TLS certificates, permissions and networking, and integrating with Git and Terraform blueprints. The guide includes checklists, worksheets, and detailed instructions for pushing/pulling container images, setting up Projects and Spaces, and choosing URL routing strategies (including the newer Context-Based URLs) to simplify domain and certificate management. It is intended for system architects, cloud engineers, and deployment teams tasked with executing an Azure-based installation of K2view’s Data Product Platform.

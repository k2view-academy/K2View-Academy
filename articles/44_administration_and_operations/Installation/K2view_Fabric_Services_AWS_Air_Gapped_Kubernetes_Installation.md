# K2view Fabric Services on Amazon AWS — Air-Gapped Kubernetes Installation

## Abstract

The *K2view Fabric Services on Amazon AWS – Air-Gapped Kubernetes Installation* guide provides detailed instructions for deploying the K2view Data Product Platform in a fully isolated, air-gapped AWS environment using Kubernetes and Helm. It explains how to install both Fabric Web Studio (for development/studio spaces) and Fabric Server (for runtime/non-dev spaces) without internet access to the orchestration platform. Key topics include prerequisites such as setting up a container registry, persistent storage, TLS certificates, and DNS; as well as configuration using Helm charts and values.yaml; security considerations including namespace isolation, encryption at rest and in transit; ingress and routing options; and operational concerns like upgrades, uninstallation, and troubleshooting. This document is intended for enterprise environments with stringent security or regulatory requirements that necessitate deployment in a disconnected state, isolated from external networks.

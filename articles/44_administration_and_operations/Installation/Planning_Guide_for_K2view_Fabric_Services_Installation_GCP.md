# Installation Planning Guide for K2view Fabric Services on GCP

## Abstract

The *Installation Planning Guide for K2view Fabric Services on GCP* provides a structured, step-by-step roadmap for preparing a Google Cloud Platform environment to install K2view Fabric Services. It covers everything from gathering environment and domain information, setting up persistent storage, configuring security (TLS certificates, IAM roles & permissions), provisioning Kubernetes clusters via Terraform and GKE, creating container registries, pushing/pulling Docker images, to creating Projects and Spaces. The guide includes checklists, worksheets, and configuration templates to help ensure that all prerequisites are met and the deployment is reliable, scalable, and aligned with best practices.

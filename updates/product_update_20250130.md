### The Fabric 8.2 Official Release

We are happy to announce that Fabric 8.2.0 has just been released and it includes the following:

* Fabric has been strengthened with **LLM GenAI integration** based capabilities, such as:
  * **LLM-based Catalog profiling** to identify sensitive data using an LLM model
  * **AI Assistant for SQL statements** to enable an effortless SQL statements creation
  * **Broadway co-pilot** which searches for required actors using a natural language
* Fabric's Catalog have been enhanced to to perform discovery based on user-defined rules. The new Discovery Pipeline screen facilitates the creation of rules that allow overriding the product baseline. 
* Catalog Settings now include the setup of **sequences** and **seed random** values for masking.
* A centralized Catalog can now be used across multiple Fabric instances (clusters).
* Fabric now supports multiple instances of the same Secret Manager type.

To get the full list of features and fixes, refer to the [Release Notes](https://support.k2view.com/Academy/Release_Notes_And_Upgrade/V8.2/Fabric_Release_Notes_V8.2.0.pdf.html) and [Upgrade Procedure to 8.2](https://support.k2view.com/Academy/Release_Notes_And_Upgrade/V8.2/Fabric_Upgrade_Procedure_To_V8.2.pdf.html).

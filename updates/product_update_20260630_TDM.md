Traditionally, creating a task required understanding exactly what data was needed, where it should come from, and how it should be safely delivered. **TDM 10 simplifies this process**. Expert users who create and manage tasks can now define **reusable, governed task templates** more efficiently by configuring default values, execution logic, permissions, and governance rules in a structured and streamlined way.

**TDM 10** introduces a **new task execution experience built around these templates**. Users can override selected execution parameters at runtime without affecting the task definition, allowing developers, testers, and security teams to provision data for a wide range of test scenarios. A new **role-based execution hub**displays only the tasks each user is authorized to execute, streamlining self-service data provisioning.

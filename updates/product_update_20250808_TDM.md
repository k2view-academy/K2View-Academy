### The TDM 9.4 Official Release

TDM 9.4 has just been released and it includes the following new features/capabilities:

* TDM V9.4.0, coupled with Fabric V8.3.0, can now provide **a native end-to-end solution for NoSQL Document Storage** (e.g., MongoDB or CouchBase), which covers the process from the Discovery to the LU creation, masking sensitive PII data, through to the data provisioning into the target system.
* **Allow Testers to Run Tasks on All Matching Entities**. This feature adds the option to grant the user permission to process unlimited number of entities in a task. 
* **TDM App — Table-level Tasks Enhancements**. Enable the user to select all tables in a given DB schema instead of selecting them one by one. 
* **Task Creation — Adding a Description on Business Parameters**. The implementor can now add a short description to the predefined business parameters. 
* **Task Execution — Adding an Execution Note to the List of Successful and Failed Entities**. Adding an execution note at the entity level. This enables the project implementor to populate execution notes on processed entities.


To get the full list of features and fixes, refer to the [Release Notes](https://support.k2view.com/Academy/Release_Notes/TDM-V9.4/TDM_Release_Notes_V9.4.pdf.html) and [TDM Upgrade Procedure to 9.4](https://support.k2view.com/Academy/articles/98_installation_and_upgrade/Upgrade_TDM/TDM_Upgrade_Procedure_to_V9.4.pdf).
